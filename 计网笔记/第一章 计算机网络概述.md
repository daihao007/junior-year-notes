# 一、网络的网络

## 1.1 计算机网络

计算机网络由若干`节点`和连接这些节点的`链路`组成

- `节点`：计算机、集线器、交换机、路由器等网络设备
- `链路`：连接节点、用于传输数据的通信通道

简单来说：

**网络 = 把许多计算机连接起来**

## 1.2 互连网

多个网络通过`路由器`相互连接，可以形成覆盖范围更大的计算机网络，这称为`互联网`，也可以理解为网络的网络

简单来说：

**互连网 = 把许多网络通过路由器连接起来**

## 1.3 互连网和互联网

- 互连网(internet)：泛指由多个网络互连形成的网络
- 互联网(Internet)：特指全球最大的、我们现在使用的互联网

关系可以理解为：

**计算机 -> 网络 -> 互连网 -> 互联网**

其中：

- 网络连接计算机
- 路由器连接不同网络
- Internet是全球最大的互连网

# 二、互联网的组成

```
你的电脑                         网站服务器
   │                                │
   │        ┌──────────────┐        │
   └────────│ 路由器 → 路由器 │────────┘
            │   → 路由器    │
            └──────────────┘
              互联网核心

 ↑                                    ↑
互联网边缘                          互联网边缘
```

从互联网的工作方式来看，可以分为`边缘部分`和`核心部分`

## 2.1 互联网的边缘部分

边缘部分由所有连接在互联网上的主机组成，由用户直接使用，用来进行**通信**和**资源共享**

处于互联网边缘部分的主机又称为`端系统`

端系统可以包括：

- 普通个人电脑
- 智能手机
- 网络摄像头
- 大型计算机
- 服务器

简单理解：

边缘部分负责产生和接收数据，是用户直接使用的部分

### 2.1.1 计算机之间通信的本质

通常所说的计算机之间通信，实际上是：

主机A中的某个进程和主机B中的另一个进程进行通信

### 2.1.2 端系统之间的两种通信方式

1. 客户/服务器方式(C/S)

    客户/服务器方式描述的是进程之间服务和被服务的关系

    - 客户(Client)：服务请求方
    - 服务器(Server)：服务提供方

    **客户程序**的主要特点：

    - 被用户调用后运行
    - 主动向服务器发起通信
    - 必须知道服务器程序的地址

    **服务器程序**的主要特点：

    - 专门提供某种服务
    - 可以同时处理多个客户请求
    - 一直运行，被动等待客户的通信请求
    - 不需要提前知道客户程序的地址

    客户和服务器建立通信关系后，通信是可以双向的，双方都可以发送和接收数据

    核心：

    **Client主动请求服务，Server被动等待并提供服务**

2. 对等连接方式(P2P)

    通信双方不固定区分服务请求方和服务提供方

    只要双方都运行P2P软件，就可以进行平等、对等的通信

    > [!NOTE]
    >
    > 本质上仍然使用客户/服务器方式，只是在P2P中：
    >
    > 每一个主机既可以作为客户，也可以作为服务器

## 2.2 互联网的核心部分

互联网的核心部分由大量网络和连接这些网络的路由器组成

核心部分的作用：

**为网络边缘中的主机提供连通性和交换，使不同主机之间能够进行通信**

核心部分中最重要的设备是路由器

- 主机：产生和接收数据
- 路由器：转发分组

**分组转发**是互联网核心部分最重要的功能

### 交换技术

典型交换技术包括：

- 电路交换
- 报文交换
- 分组交换

互联网的核心部分采用**分组交换**技术

### 交换的含义

从通信资源分配的角度来看，交换就是按照某种方式动态分配传输线路的资源

### 1. 电路交换

例子：**传统电话**

电路交换需要经过三个阶段：

1. 建立连接：建立一条专用的物理通路，占用通信资源
2. 通话：双方进行通信，并一直占用通信资源
3. 释放连接：释放专用物理通路，归还通信资源

电路交换的特点：

通信双方在通信过程中始终占用端到端的通信资源

> [!NOTE]
>
> 计算机数据具有突发性。如果使用电路交换，及时某段时间没有数据传输，已经建立的通信线路仍然被占用，因此可能导致通信线路利用率较低

### 2. 分组交换

* 互联网采用分组交换技术，并采用存储转发方式

* 发送端首先把较长的`报文`划分为较小的`数据段`，在每个数据段前添加`首部`，就构成一个`分组`，即

    **分组 = 首部 + 数据**

    其中：

    - 分组也称为包
    - 分组首部也称为包头

* 首部：首部中包含**目的地址**、**源地址**等重要控制信息

* 路由器根据分组首部中的目的地址进行转发

* 路由器处理分组的基本过程：

    1. 暂存收到的分组
    2. 检查分组首部
    3. 查找转发表
    4. 根据目的地址找到合适的借口
    5. 将分组转发出去

    这种方式称为**存储转发**

### 分组的转发

* 每一个分组在互联网中独立选择传输路径，因此同一报文的不同分组不一定经过完全相同的路径
* 位于网络核心部分的路由器负责转发分组
* 接受端收到各个分组后，剥去分组首部，并还原成原来的报文

### 分组交换的优点

1. 高效

   在分组传输过程中动态分配传输带宽，对通信链路是逐段占用

2. 灵活

   每一个分组可以独立选择合适的转发路由

3. 迅速

   以分组作为传输单位，不需要预先建立连接就可以发送分组

4. 可靠

   通过可靠性的网络协议以及分布式、多路由的分组交换网，使网络具有较好的生存性

### 分组交换带来的问题

1. 排队时延

   分组在路由器中进行存储转发时可能需要排队，因此会产生排队时延

2. 不保证带宽

   分组交换采用动态分配方式，因此不能保证固定的通信带宽

3. 增加开销

   每个分组必须携带首部等控制信息，同时路由器还需要暂存分组、维护转发表等，因此会产生额外开销

### 3. 报文交换

* 同样采用存储转发方式
* 报文交换以整个报文作为存储转发的单位，而分组交换会把报文划分为较小的分组，再分别进行存储转发
* 由于报文交换的时延较长，现在已经很少使用

### 4. 三种交换方式的比较

#### 电路交换

特点：

- 通信前需要建立连接
- 通信过程中始终占用端到端的通信资源
- 通信结束后释放连接
- 适合连续传送大量数据

#### 报文交换

特点：

- 不需要预先建立连接
- 采用存储转发
- 以**整个报文**作为存储转发单位
- 时延较长

#### 分组交换

特点：

- 不需要预先建立连接
- 采用存储转发
- 将报文划分为较小的分组进行传输
- 每个分组可以独立选择传输路径
- 网络资源利用率较高
- 是互联网核心部分采用的交换方式

> [!NOTE]
>
> 对于突发式数据，报文交换和分组交换不需要预先分配传输带宽，因此可以提高网络的信道利用率
>
> 由于分组长度通常远小于整个报文的长度，因此分组交换比报文交换的时延更小，同时具有更好的灵活性

```
                   交换
                    │
       ┌────────────┼────────────┐
       ↓            ↓            ↓
    电路交换      报文交换      分组交换 ★
       │            │            │
    建立连接      存储转发      存储转发
       │            │            │
   独占通信资源    整个报文      切成分组
       │            │            │
   连续大量数据    时延较长     逐段占用链路
                                 │
                          每个分组独立选路
                                 │
                           互联网采用
```

# 三、计算机网络的类别

计算机网络有很多类别,可以按一下方法分类：

- 按照网络的作用范围进行分类
- 按照网络的使用者分类
- 用来把用户接入到互联网的网络

## 3.1 按照网络的作用范围进行分类

| 类别           | 作用范围或距离                                             |
| -------------- | ---------------------------------------------------------- |
| 广域网 WAN     | 通常为几十到几千公里，有时也称为远程网，是互联网的核心部分 |
| 城域网 MAN     | 作用范围一般是一个城市，作用距离约为5~50公里               |
| 局域网 LAN     | 局限较小的范围(如一公里左右)，通常采用高速通信线路         |
| 个人区域网 PAN | 范围很小，大约在10米左右，有时也称为无线个人区域网WPAN     |

若中央处理机之间的距离非常近，则一般称之为多处理机系统，而不称它为计算机网络

## 3.2 按照网络的使用者进行分类

| 类别   | 作用范围或距离                                     |
| ------ | -------------------------------------------------- |
| 公用网 | 按规定缴纳费用的人都可以使用的网络，也可称为公众网 |
| 专用网 | 为特殊业务工作的需要而建造的网络                   |

公用网和专用网都可以传送多种业务，如传送的是计算机数据，则分别是公用计算机网络和专用计算机网络

## 3.3 用来把用户接入互联网的网络

**接入网AN**：

- 又称为本地接入网或居民接入网
- 用于将用户接入互联网
- 实际就是本地ISP所拥有的网络，它既不是互联网的核心部分，也不是互联网的边缘部分
- 是从某个用户端系统到本地ISP的第一个路由器(也称为边缘路由器)之间的一种网络
- 从覆盖的范围来看，很多接入网还是属于局域网
