# 一、网络层的几个重要概念

## 1.1 网络层提供的两种服务

### 1. 网络层的两种设计思想

网络层需要解决两个核心问题：

- 向运输层提供面向连接还是无连接的服务？
- 可靠交付由网络负责还是端系统负责？

由此产生两种服务：

1. **虚电路服务**：面向连接，强调由网络保证可靠交付
2. **数据报服务**：无连接，网络尽最大努力交付，由端系统负责可靠通信

### 2. 虚电路服务

基本思想：模仿电信网络，采用面向连接的分组交换方式

工作过程：

1. 建立连接：通信前建立虚电路VC
2. 数据传输：同一虚电路上的分组沿预先确定的路径转发
3. 释放连接：通信结束后释放相关资源

特点：

- 需要预先建立逻辑连接
- 同一虚电路的分组沿相同路径转发
- 分组通常发送顺序到达
- 若配合可靠传输协议，可实现无差错、无丢失、无重复的按序交付
- 路径上的节点发生故障，经过该节点的虚电路可能失效

> [!NOTE]
>
> 虚电路是逻辑连接，不是独占的物理连接，仍然采用存储转发方式。建立虚电路本身不等于实现可靠传输

### 3. 数据报服务

互联网采用无连接、尽最大努力交付的数据报服务

特点：

- 发送数据前不需要建立连接
- 每个IP 数据报独立发送、独立转发
- 不同数据报可能经过不同路径
- 网络层不保证可靠交付，可能发生丢失、重复、失序等问题
- 不保证分组的传输时限
- 可靠通信由端系统负责，例如使用TCP实现可靠传输

尽最大努力交付：网络尽力转发分组，但不承诺一定成功送达

### 4. 虚电路服务与数据报服务对比

| 对比项目 | 虚电路服务               | 数据报服务               |
| -------- | ------------------------ | ------------------------ |
| 连接建立 | 必须建立                 | 不需要                   |
| 通信方式 | 面向连接                 | 无连接                   |
| 目的地址 | 建立后使用虚电路号       | 每个分组携带完整目的地址 |
| 分组路径 | 同一虚电路沿相同路径     | 每个分组独立转发         |
| 分组顺序 | 通常按序到达             | 可能失序                 |
| 节点故障 | 经过故障节点的虚电路失效 | 可能丢包或改变路由       |
| 可靠性   | 可由网络保证             | 由端系统保证             |
| 典型设计 | 虚电路网络               | 互联网IP网络             |

### 5. 为什么互联网采用数据报服务

- 简化网络层设计，降低中间路由器的复杂性
- 不需要为每次通信预先建立网络层连接
- 能够灵活适应网络拓扑变化
- 更容易实现不同类型网络之间的互连
- 将可靠通信功能交由端系统按需实现

## 1.2 网络层的两个层面

### 1. 网络层的两个层面

不同网络中的两台主机进行通信，需要经过若干路由器转发分组

路由器之间传送的信息主要分为两类：

1. 数据：需要传输到目的主机的信息
2. 路由信息：用于确定数据传输路径的信息

网络层由两个层面组成：

- 数据层面：负责分组转发
- 控制层面：负责路由转发

### 2. 数据层面

定义：路由根据本地转发表，将收到的分组从对应的输出接口转发出去

工作过程：

1. 接收IP数据报
2. 根据目的IP地址查找转发表
3. 确定下一跳和输出接口
4. 将分组转发出去

特点：

- 根据已有的转发表转发分组
- 各路由器独立执行转发操作
- 通常采用硬件实现高速转发
- 不需要针对每个分组重新计算路由

### 3. 控制层面

定义：通过路由选择协议和路由选择算法计算路由，建立路由表，并为数据层面的分组转发提供依据

主要功能：

- 收集和交换路由信息
- 运行路由选择算法
- 计算到目的网络的路由
- 建立和更新路由表
- 为转发表的生成和更新提供依据

特点：

- 传统分布式路由选择需要多个路由器协同工作
- 通常采用软件进行路由计算，相对较慢
- 网络拓扑变化时，需要更新相关路由信息

### 4. 路由选择和分组转发

| 对比项目 | 路由选择               | 分组转发             |
| -------- | ---------------------- | -------------------- |
| 所属层面 | 控制层面               | 数据层面             |
| 核心问题 | 应该选择哪条路径       | 应该从哪个接口转发   |
| 主要依据 | 路由信息与路由选择算法 | 转发表               |
| 工作特点 | 多个路由协同计算       | 当前路由器独立执行   |
| 实现方式 | 主要通过软件计算       | 通常采用硬件高速转发 |

路由选择决定路径，分组转发执行转发操作

### 5. 路由表和转发表

- 路由表：保存路由信息和路由选择结果，主要属于控制层面
- 转发表：用于实际分组转发，主要属于数据层面

两者的关系

```
路由选择算法->路由表->转发表->分组转发
```

### 6. 软件定义网络 SDN

核心思想：将网络的控制层面和数据层面分离

传统网络：

- 每个路由器运行自己的路由选择功能
- 路由器之间交换路由信息
- 各路由器建立本地转发表
- 根据转发表转发分组

SDN：

- 由远程控制器负责路由计算与控制
- 控制器为各路由器生成并下发转发表
- 路由器根据转发表转发分组

优点：

- 便于网络集中管理
- 有利于统一制定转发策略
- 提高网络控制与配置的灵活性

# 二、网际协议 IP

与IPv4配套的三个重要协议：

| 协议 | 中文名称         | 作用                       |
| ---- | ---------------- | -------------------------- |
| ARP  | 地址解析协议     | 根据IP地址解析MAC地址      |
| ICMP | 网际控制报文协议 | 传递差错报告和网络控制信息 |
| IGMP | 网际组管理协议   | 管理IPv4多播组成员关系     |

IP 是网络层的核心协议，为异构网络提供统一的逻辑寻址恶化数据报转发机制

## 2.1 虚拟互连网络

### 1. 异构网络的互连问题

- 寻址方案
- 最大分组长度
- 网络接入机制
- 超时控制
- 差错恢复方法
- 状态报告方法
- 路由选择技术
- 用户接入控制
- 管理与控制方式
- 提供的服务

实现互连的方案：通过中间设备互连：保留不同网络的技术特点，实现网络之间的通信

### 2. 网络互连设备

| 层次         | 中间设备                   | 主要作用             |
| ------------ | -------------------------- | -------------------- |
| 运输层及以上 | 网关Gateway                | 高层协议转换         |
| 网络层       | 路由器 Router              | 根据IP地址转发数据报 |
| 数据链路层   | 网桥 Bridge、交换机 Switch | 根据链路层地址转发帧 |
| 物理层       | 转发器 Repeater            | 转发或再生物理信号   |

> [!NOTE]
>
> - 转发器、网桥或普通二层交换机主要用于扩展网络，不构成网络层意义上的不同IP网络互连
> - 具有不同网络前缀的网络之间通常需要通过路由器实现互连
> - 普通二层交换机主要根据MAC地址转发帧；路由器根据IP地址进行数据报转发

### 3. 虚拟互连网络的概念

虚拟互连网络：通过路由器连接多个异构网络，并利用统一的IP协议，在网络层将这些网络抽象成一个逻辑上统一的网络

核心思想：

- 底层网络可以采用不同的物理层和数据链路层技术
- 网络层统一使用IP协议进行逻辑寻址和分组转发
- IP层屏蔽底层网络的异构细节
- 不同网络中的主机能够像处于统一网络中一样进行通信

IP网的意义：使用户不必关心底层网络的具体类型和技术差异，简化跨网络通信

### 4. IP数据报在互联网中的传输

传输过程：

1. 源主机生成IP数据报，并封装成链路层帧发送
2. 路由器接收帧，取出IP数据报
3. 路由器根据目的IP地址查找转发表
4. 确定下一跳及输出接口
5. 重新进行相应的链路层封装并发送
6. 重复上述过程，直到到达目的网络和目的主机

网络分层特点：

- 主机使用完整的协议栈
- 普通路由器进行IP转发时柱哟啊处理物理层、数据链路层和网络层
- IP数据报实现跨网络传输
- 链路层帧负责具体链路上的传输

### 5. 直接交付和间接交付

直接交付：

- 目的主机位于当前节点直接连接的IP网络中
- 不需要其他路由器继续转发
- 数据报可以通过本地链路交给目的主机

间接交付：

- 目的主机不在当前节点直接连接的网络中
- 需要将数据报交给下一跳路由器
- 由后续路由器继续完成转发

## 2.2 IP 地址

### 1. IP地址的概念及表示方法

IP地址是网络层用于逻辑寻址的地址

IPv4 地址长度为32位，采用点分十进制记法：

- 每8位二进制数为一组
- 每组转换为0～255的十进制数
- 四组十进制数使用小数点连接

IP地址标识网络接口，而不只是整台主机或路由器

### 2. IP 地址的两级结构

传统IP 地址分为两个部分：

IP地址={网络号，主机号}

- 网络号：标识主机所在的网络
- 主机号：标识该网络中的具体接口

网络号越长，主机号越短；网络号越短，单个网络的主机编号空间越大

### 3. 分类的IP地址

| 类别 | 起始比特 | 第一字节范围 | 网络号位数 | 主机号位数 | 用途     |
| ---- | -------- | ------------ | ---------- | ---------- | -------- |
| A    | 0        | 0～127       | 8          | 24         | 单播     |
| B    | 10       | 128～191     | 16         | 16         | 单播     |
| C    | 110      | 192～223     | 24         | 8          | 单播     |
| D    | 1110     | 224～239     | -          | -          | 多播     |
| E    | 1111     | 240～255     | -          | -          | 主要保留 |

A类地址：

- 最高位固定为0
- 网络号8位，主机号24位
- 最大可指派网络数：$2^7-2=126$
- 可指派网络号范围：1～126
- 每个网络最大主机数：$2^24-2=16777214$

**B 类地址**

- 前两位固定为 10。
- 网络号 16 位，主机号 16 位。
- 传统规则下最大可指派网络数：$2^14 - 1 = 16383$。
- 可指派网络号范围：128.1～191.255。
- 每个网络最大主机数：$2^16 - 2 = 65534$。

**C 类地址**

- 前三位固定为 110。
- 网络号 24 位，主机号 8 位。
- 传统规则下最大可指派网络数：$2^21 - 1 = 2097151$。
- 可指派网络号范围：192.0.1～223.255.255。
- 每个网络最大主机数：$2^8 - 2 = 254$。

**D 类地址**

- 前四位固定为 1110。
- 用于 IP 多播。

**E 类地址**

- 前四位固定为 1111。
- 主要保留用途，其中部分地址具有特殊用途。

### 4. 最大可指派主机数

对于普通IPv4网络：
$$
最大可指派主机数=2^h-2
$$
其中h是主机号位数

减去2的原因：

- 主机号全0：通常表示网络地址
- 主机号全1：通常表示广播地址

### 5. 特殊的IP地址

本地环回地址

- 127.0.0.1: 用于本机网络协议栈测试
- 127.0.0.0/8: 环回地址范围

链路本地地址

- 169.254.0.0/16: 系统未获得正常地址配置时，可能自动使用的本地链路地址范围

私有IP地址

| 地址块         | 范围                         |
| -------------- | ---------------------------- |
| 10.0.0.0/8     | 10.0.0.0～10.255.255.255     |
| 172.16.0.0/12  | 172.16.0.0～172.31.255.255   |
| 192.168.0.0/16 | 192.168.0.0～192.168.255.255 |

私有地址可以在不同内部网络中重复使用，但不能直接作为公网可路由地址

其他特殊地址：

- 0.0.0.0: 可以表示尚未确定本机IPv4的值等含义
- 网络号为0、主机号为X：传统规则下表示本网络中编号为X的主机
- 255.255.255.255: 本地有限广播地址，路由器不转发
- 网络号为Y、主机号全是1: 指向指定网络的定向广播地址
- 127.0.0.1: 本机环回测试

### 6. 分类IP地址的优缺点

优点：

- 管理简单，使用方便
- 有利于按网络号进行路由转发
- 可以进一步划分子网

缺点：

- A、B、C类地址块大小固定
- 地址分配不够灵活
- 容易造成IPv4地址资源浪费
- 无法从根本上解决IPv4地址枯竭问题

因此，引入无分类编址CIDR，使网络前缀长度可以灵活变化
