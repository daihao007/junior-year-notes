# 使用顺序

1. 语义分析实现方案.pptx：投屏讲解，只有一页，演讲者备注中含讲稿。
2. 两分钟讲解稿.txt：按实际语速调整为约 2–3 分钟。
3. 代码讲解与答辩问答.html：双击离线阅读，包含 22 个追问与当前工作区的源码行号链接。源码更新后行号可能变化。
4. 代码片段速读.md：五段核心源码。代码快照文件夹用于移动到其他电脑后查阅。
5. demo：四组已验证输入及输出。若离开原电脑，用快照编译并从各 demo 目录运行。

快照编译：进入代码快照目录，执行 gcc -Wall -Wextra -std=c11 parser.c token.c syntax_tree.c error_list.c symbol.c semantic.c -o compiler_demo.exe；确认成功后，在某个 demo 样例目录执行 ..\..\代码快照\compiler_demo.exe。

演示程序只分析输入，不执行 SysY。样例中的局部 x 用于说明作用域，未做初始化；当前语义检查没有实现变量确定赋值分析。
