# 一、文法逐条解读

## 1.1 CompUnit(编译单元)

文法：

CompUnit → {Decl} {FuncDef} MainFuncDef


含义：

一个 SysY 程序由：
1. 若干全局声明（可以没有）
2. 若干普通函数定义（可以没有）
3. 一个 main 函数组成


其中：
Decl:
    - ConstDecl 常量声明
    - VarDecl 变量声明

FuncDef:
    普通函数定义

MainFuncDef:
    固定形式 int main(){}


注意：
- SysY 必须且只能存在一个 main 函数
- 全局声明必须出现在函数定义之前
- 普通函数可以不存在

## 1.2 Decl(声明)

文法：

Decl → ConstDecl | VarDecl


含义：

声明分为：
1. 常量声明
2. 变量声明


ConstDecl:

const BType ConstDef {, ConstDef};


特点：
- 必须初始化
- 初始化值必须是 ConstExp
- 支持普通常量和数组常量


BType:

BType → int | char


ConstDef:

Ident ['[' ConstExp ']']=' ConstInitVal


表示：
- 普通常量：
  const int a=10;

- 常量数组：
  const int arr[3]={1,2,3};


ConstInitVal:
- ConstExp
- 数组初始化
- 字符串初始化

## 1.3 VarDecl（变量声明）

文法：

VarDecl → ['static'] BType VarDef {',' VarDef} ';'


组成：

1. static（可选）
2. 类型 int/char
3. 一个或多个变量定义
4. 分号


VarDef:

1. 无初始化：
int a;

2. 有初始化：
int a=10;

3. 数组：
int arr[10];

4. 数组初始化：
int arr[3]={1,2,3};


InitVal:

- Exp
- 数组初始化
- StringConst


注意：
- static只能修饰局部变量
- 变量可以没有初始值
- 数组长度必须是ConstExp
- {,VarDef}需要覆盖0次和多次情况

## 1.4 FuncDef（函数定义）

### 1. 函数定义

文法：

FuncDef → FuncType Ident '(' [FuncFParams] ')' Block

含义：

一个普通函数由以下部分组成：

- FuncType：函数返回类型
- Ident：函数名
- FuncFParams：函数形参表，可以不存在
- Block：函数体

例如：

int add(int a, int b) {
    return a + b;
}

需要覆盖：
- 无形参函数
- 有形参函数


### 2. FuncType（函数类型）

文法：

FuncType → 'void' | 'int' | 'char'

SysY 普通函数支持三种返回类型：

- void：无返回值
- int：返回 int
- char：返回 char

例如：

void f() {
    return;
}

int getInt() {
    return 1;
}

char getChar() {
    return 'A';
}

函数返回值类型必须和 FuncType 一致。


### 3. FuncFParams（函数形参表）

文法：

FuncFParams → FuncFParam { ',' FuncFParam }

表示函数至少有一个形参，后面可以继续出现多个形参。

例如：

int f(int a)

int f(int a, int b, int c)

覆盖时需要考虑：
- {',' FuncFParam} 重复 0 次，即只有一个形参
- {',' FuncFParam} 重复多次，例如三个形参


### 4. FuncFParam（函数形参）

文法：

FuncFParam → BType Ident ['[' ']']

形参分为两种：

1. 普通参数

int f(int a)

其中 int a 是普通参数。

2. 一维数组参数

int f(int arr[])

其中 int arr[] 是数组参数。

注意数组形参与普通数组定义的区别：

普通数组定义：

int arr[10];

VarDef 中数组长度为 ConstExp，需要写数组长度。

数组形参：

int f(int arr[])

FuncFParam 中 [] 不需要填写数组长度。


### 5. 参数传递

普通 int、char 参数按值传递。

例如：

void f(int x)

调用：

int a = 10;
f(a);

传递的是 a 的值。


数组参数传递的是数组的起始地址。

例如：

void f(int arr[]) {
    arr[0] = 10;
}

int a[3] = {1, 2, 3};
f(a);


函数调用时实参和形参的类型必须完全一致。

例如：

void f1(int x);
void f2(int x[]);

int a = 10;
int arr[3] = {1, 2, 3};

f1(a);       // 合法，int → int
f1(arr[0]);  // 合法，数组元素是 int
f1(arr);     // 不合法，int[] → int
f2(arr);     // 合法，int[] → int[]


### 6. MainFuncDef（主函数）

文法：

MainFuncDef → 'int' 'main' '(' ')' Block

主函数形式固定为：

int main() {
    ...
    return 0;
}

注意：

- main 的返回类型只能是 int
- main 没有参数
- 一个 SysY 程序有且仅有一个 main
- main 的返回值只能为常数 0


### 7. 函数部分覆盖要求

需要覆盖：

- FuncDef 有参数
- FuncDef 无参数
- FuncType → void
- FuncType → int
- FuncType → char
- FuncFParams 只有一个参数
- FuncFParams 有多个参数
- FuncFParam 普通变量参数
- FuncFParam 一维数组参数
- BType → int
- BType → char
- MainFuncDef

## 1.5 Block（语句块）

文法：

Block → '{' { BlockItem } '}'

含义：

Block 表示由一对大括号包围的语句块，其中可以包含 0 个或多个 BlockItem。

例如：

{
    int a = 10;
    a = a + 1;
}

### BlockItem

文法：

BlockItem → Decl | Stmt

表示语句块中的一项可以是：

1. 声明 Decl
2. 语句 Stmt

例如：

{
    int a = 10;   // Decl
    a = a + 1;    // Stmt
    return a;     // Stmt
}

### Block 与作用域

每个 Block 都会创建一个新的作用域。

内层 Block 可以定义和外层 Block 同名的变量：

int a = 10;

{
    int a = 20;
}

此时内层的 a 会隐藏外层的 a。

但是同一个 Block 中不能重复定义同名变量。

### Block 的覆盖要求

Block → '{' { BlockItem } '}'

需要覆盖：

- BlockItem 重复 0 次，即空 Block
- BlockItem 重复多次

BlockItem → Decl | Stmt

需要覆盖：

- Decl
- Stmt


## 1.6 Stmt（语句）

文法：

Stmt → LVal '=' Exp ';'
     | [Exp] ';'
     | Block
     | 'if' '(' Cond ')' Stmt [ 'else' Stmt ]
     | 'while' '(' Cond ')' Stmt
     | 'switch' '(' Exp ')' '{' { CaseStmt } '}'
     | 'break' ';'
     | 'continue' ';'
     | 'return' [Exp] ';'
     | 'printf' '(' StringConst { ',' Exp } ')' ';'

Stmt 表示 SysY 中的各种语句。


### 1. 赋值语句

文法：

Stmt → LVal '=' Exp ';'

例如：

a = 10;

a = b + 1;

arr[2] = 100;

其中：

- LVal 表示左值
- Exp 表示右侧表达式

LVal 可以表示普通变量或者数组元素。

注意：常量不能被赋值。


### 2. 表达式语句

文法：

Stmt → [Exp] ';'

Exp 是可选的。

有 Exp：

a + 1;

f();

表达式会被计算，但计算结果可以被丢弃。

无 Exp：

;

这是一条空语句，什么也不执行。

覆盖时需要同时覆盖：
- 有 Exp
- 无 Exp


### 3. Block 语句

文法：

Stmt → Block

例如：

{
    int a = 10;
    a = a + 1;
}

一个完整的 Block 本身也可以作为一条 Stmt。

### 4. if 语句

文法：

Stmt → 'if' '(' Cond ')' Stmt [ 'else' Stmt ]

表示 if 语句，其中 else 是可选的。

无 else：

if (a > 10)
    a = 10;

有 else：

if (a > 10)
    a = 10;
else
    a = 20;

实验需要同时覆盖：
- 无 else
- 有 else

if 后面要求的是 Stmt，而 Block 本身也是一种 Stmt，因此可以写：

if (a > 10) {
    a = 10;
}

else 与最近的、尚未匹配 else 的 if 匹配。


### 5. while 语句

文法：

Stmt → 'while' '(' Cond ')' Stmt

例如：

while (a < 10) {
    a = a + 1;
}

while 后面同样是 Stmt，因此既可以直接写一条语句，也可以使用 Block。


### 6. break

文法：

Stmt → 'break' ';'

break 用于直接结束当前 while 循环或 switch 语句。

例如：

while (a < 10) {
    if (a == 5) {
        break;
    }
    a = a + 1;
}

break 可以出现在：
- while
- switch


### 7. continue

文法：

Stmt → 'continue' ';'

continue 用于跳过当前这一轮循环的剩余部分，继续下一轮循环。

例如：

while (a < 10) {
    a = a + 1;

    if (a == 5) {
        continue;
    }
    
    printf("%d\n", a);
}

continue 只能出现在 while 循环中。

区别：

break：结束整个循环

continue：结束当前这一轮，继续下一轮


### 8. switch

文法：

Stmt → 'switch' '(' Exp ')' '{' { CaseStmt } '}'

例如：

switch (a) {
    case 1:
        printf("one\n");
        break;

    case 2:
        printf("two\n");
        break;
    
    default:
        printf("other\n");
}

注意：

if、while 中使用 Cond。

switch 中使用 Exp。


### 9. CaseStmt

文法：

CaseStmt → 'case' Number ':' { Stmt }
         | 'default' ':' { Stmt }

CaseStmt 有两种：

1. case

case 1:
    a = 10;
    break;

2. default

default:
    a = 20;

实验中 case 和 default 都需要覆盖。


### 10. switch 语义约束

case 后面是 Number：

Number → IntConst | CharConst

因此可以使用：

case 1:

或者：

case 'a':

switch 的 Exp 与 case 的 Number 类型必须一致。

例如：

int a = 1;

switch (a) {
    case 1:
        break;
}

或者：

char c = 'a';

switch (c) {
    case 'a':
        break;
}

一个 switch 中：
- 不能存在重复的 case 常量值
- 最多只能存在一个 default


### 11. switch 的 fall-through

如果 case 后没有 break，会继续执行后面的 case。

例如：

switch (a) {
    case 1:
        printf("A\n");

    case 2:
        printf("B\n");
        break;
}

如果 a = 1，则会输出：

A
B

因此 break 在 switch 中用于结束当前 switch。


### 12. 本部分覆盖要求

需要覆盖：

- if 无 else
- if 有 else
- while
- switch
- case
- default
- break
- continue

### 13. return 语句

文法：

Stmt → 'return' [Exp] ';'

其中 Exp 是可选的，因此 return 有两种形式。


#### 不带返回值

return;

主要用于 void 函数：

void f() {
    return;
}


#### 带返回值

return Exp;

例如：

int f() {
    return 10;
}

或者：

int add(int a, int b) {
    return a + b;
}


#### 1. return 的类型要求

函数返回值类型需要和 FuncType 一致。

void 函数：

void f() {
    return;
}

int 函数：

int f() {
    return 10;
}

char 函数：

char f() {
    return 'A';
}

SysY 中 int 和 char 是不同类型，不进行默认的混合类型转换。

如果需要转换，可以使用显式类型转换。


#### 2. 有返回值函数的要求

实验中的合法测试程序保证：

int 和 char 等有返回值函数的最外层 Block 最后一条语句为显式 return。

例如：

int f() {
    int a = 10;
    return a;
}


#### 3. main 函数返回值

main 的形式：

int main() {
    ...
    return 0;
}

main 函数返回值只能为常数 0。


#### 4. return 的覆盖要求

Stmt → 'return' [Exp] ';'

需要覆盖：

- Exp 不存在：return;
- Exp 存在：return Exp;


### 14. printf 语句

文法：

Stmt → 'printf' '(' StringConst { ',' Exp } ')' ';'


#### 1. 不带 Exp

printf("hello\n");

此时：

{ ',' Exp }

重复 0 次。


#### 2. 带 Exp

例如：

printf("%d\n", a);

其中：

"%d\n" → StringConst

a → Exp


#### 3. 带多个 Exp

例如：

printf("%d %d %d\n", a, b, c);

此时：

{ ',' Exp }

重复多次。


#### 4. printf 格式符

SysY 支持：

%d → int
%c → char
%s → 字符串或 char 数组

例如：

int a = 10;
char c = 'A';
char str[6] = "hello";

printf("%d\n", a);
printf("%c\n", c);
printf("%s\n", str);


#### 5. printf 注意事项

printf 中格式占位符和对应表达式需要匹配。

例如：

printf("%d %c\n", a, c);

%d 对应 int 类型；
%c 对应 char 类型。


#### 6. printf 覆盖要求

需要覆盖：

- { ',' Exp } 重复 0 次
- { ',' Exp } 重复多次


### 15. Stmt 总结

Stmt 包括：

1. 赋值语句

a = 10;

2. 表达式语句

a + 1;

3. 空语句

;

4. Block

{
    ...
}

5. if

if (Cond)
    Stmt;

6. if-else

if (Cond)
    Stmt;
else
    Stmt;

7. while

while (Cond)
    Stmt;

8. switch

switch (Exp) {
    case Number:
        ...
    default:
        ...
}

9. break

break;

10. continue

continue;

11. return

return;
return Exp;

12. printf

printf("...");
printf("%d", Exp);
