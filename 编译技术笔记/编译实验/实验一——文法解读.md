# 一、文法逐条解读

## 1.1 CompUnit(编译单元)

文法：

CompUnit → {Decl} {FuncDef} MainFuncDef


含义：

一个 SysY 程序由：
1. 若干全局声明（可以没有）
2. 若干普通函数定义（可以没有）
3. 一个 main 函数组成


其中：
Decl:
    - ConstDecl 常量声明
    - VarDecl 变量声明

FuncDef:
    普通函数定义

MainFuncDef:
    固定形式 int main(){}


注意：
- SysY 必须且只能存在一个 main 函数
- 全局声明必须出现在函数定义之前
- 普通函数可以不存在

## 1.2 Decl(声明)

文法：

Decl → ConstDecl | VarDecl


含义：

声明分为：
1. 常量声明
2. 变量声明


ConstDecl:

const BType ConstDef {, ConstDef};


特点：
- 必须初始化
- 初始化值必须是 ConstExp
- 支持普通常量和数组常量


BType:

BType → int | char


ConstDef:

Ident ['[' ConstExp ']']=' ConstInitVal


表示：
- 普通常量：
  const int a=10;

- 常量数组：
  const int arr[3]={1,2,3};


ConstInitVal:
- ConstExp
- 数组初始化
- 字符串初始化

## 1.3 VarDecl（变量声明）

文法：

VarDecl → ['static'] BType VarDef {',' VarDef} ';'


组成：

1. static（可选）
2. 类型 int/char
3. 一个或多个变量定义
4. 分号


VarDef:

1. 无初始化：
int a;

2. 有初始化：
int a=10;

3. 数组：
int arr[10];

4. 数组初始化：
int arr[3]={1,2,3};


InitVal:

- Exp
- 数组初始化
- StringConst


注意：
- static只能修饰局部变量
- 变量可以没有初始值
- 数组长度必须是ConstExp
- {,VarDef}需要覆盖0次和多次情况
